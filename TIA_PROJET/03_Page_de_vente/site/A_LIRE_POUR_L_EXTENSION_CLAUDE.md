# Site Trading IA Academy — instructions de mise en ligne

Ce dossier est un site statique complet, prêt à héberger tel quel :
- `index.html` : la page de vente (HTML + CSS intégrés, polices Google Fonts).
- `logo.png` : logo TIA (aussi utilisé comme favicon).
- `img/` : 6 photos (licence Unsplash, crédits en bas de page).

## À faire pour la mise en ligne
1. **Héberger** le dossier tel quel (Netlify, Vercel, GitHub Pages, Hostinger ou autre). Aucun build n'est nécessaire.
2. **Brancher le paiement** : tous les boutons pointent vers `#offre`. Le bouton principal a l'identifiant `cta-paiement`. Remplace son `href` (et celui des autres boutons si besoin) par le lien de paiement de la plateforme choisie (Stripe Payment Link, Systeme.io, Podia, etc.).
   - Prix de lancement : **64 €**, limité aux **100 premiers acheteurs**, puis **97 €**. Configure la limite de quantité dans la plateforme de paiement.
3. **Ajouter les pages obligatoires** (France) et les relier dans le pied de page : **Mentions légales**, **CGV** (avec le droit de rétractation de 14 jours), **Politique de confidentialité**, **Contact**.
4. **Domaine** : relier un nom de domaine si besoin.

## À ne pas modifier
- L'**avertissement sur les risques** (en haut et en bas de page) doit rester visible.
- Aucune promesse de gains, aucun signal, aucun faux témoignage ni fausse urgence ne doivent être ajoutés.
